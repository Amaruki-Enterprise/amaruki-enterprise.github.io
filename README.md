# Amaruki — Portafolio

Contacto público: amarukienterprise@gmail.com. Sitio de portafolio de Amaruki Enterprise, preparado para https://amaruki-enterprise.github.io/ y alojado en GitHub Pages.

## Contenido
- La Mesa: catálogo conceptual de un negocio ficticio. Imágenes ilustrativas de IA y precios de ejemplo; no es un trabajo de cliente.
- Amaruki: dirección visual y portafolio propios.
- Presentación del estudio, filtros de trabajos y correo de contacto.

## Agregar trabajos
1. Obtener autorización del cliente para publicar el trabajo, sus imágenes y nombre comercial.
2. Guardar los archivos públicos finales en assets/ con nombres simples.
3. Duplicar un bloque article.project-card de index.html. Cambiar título, imagen, descripción, enlace, categoría y fecha.
4. Actualizar contador y filtros si corresponde. Los ejemplos deben conservar la etiqueta de concepto.
5. Confirmar cambios en GitHub para que Pages actualice el sitio.

Solo se publicarán los archivos del portafolio. Las listas de candidatos y borradores comerciales quedan fuera.

GitHub Pages gratuito: repositorio público, fuente main y carpeta raíz. Los recursos usan rutas relativas y funcionan bajo una ruta de proyecto. No requiere dominio de pago, instalación ni servidor propio.

El sitio muestra proyectos y contacto; no procesa ventas ni pagos. Referencia oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits
