# Amaruki Enterprise — Agencia de marketing digital integral

Web pública y portafolio: https://amaruki-enterprise.github.io/
Contacto: amarukienterprise@gmail.com

## Servicios
- Branding e identidad corporativa: logotipo, manual, colores, tipografías y diseño de material corporativo.
- Desarrollo y diseño web: sitios corporativos, e-commerce, móviles, UX/UI y SEO.
- Gestión de redes sociales: estrategia, calendario, gráficos, videos y comunidad.
- Publicidad digital: Google Ads, Meta Ads y seguimiento de métricas y ROI.

## Portafolio
Amaruki es un proyecto propio. La Mesa es una demostración de un negocio ficticio, con imágenes de IA y precios de ejemplo. No se presentan como clientes ni como resultados de campañas.

Para agregar trabajos, obtener autorización del cliente y añadir un article.project-card en index.html, con imagen, descripción, enlace y data-category. Actualizar filtros y contador. Mantener visible la naturaleza de cada proyecto.

## Contacto
El formulario valida negocio, servicio y descripción, prepara un borrador con mailto y muestra texto copiable. El visitante debe enviarlo desde su aplicación de correo. No existe un backend, almacenamiento de datos ni confirmación de envío en la web. El correo directo permanece disponible sin JavaScript. No se procesan pagos.

## Diseño
Identidad carbón, marfil y oliva; logo original en assets. CSS con tokens de color, tipografía y espaciado, navegación adaptable, foco visible, filtros anunciados y movimiento reducido. Habilidades consultadas: ui-ux-pro-max y design-system de la carpeta local Empresa.

## Publicación y mantenimiento
HTML, CSS y JavaScript sin dependencias de compilación. GitHub Pages usa main y la raíz. Mantener .nojekyll y assets existentes. Al modificar CSS o JS, cambiar la versión de sus enlaces en index.html.
Revisar móvil y escritorio, navegación por teclado, filtros, preguntas frecuentes y consulta de correo antes de publicar.
